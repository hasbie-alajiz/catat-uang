Project belajar, tujuannya agar lebih memahami materi html, css, dan javascript yang sudah dipelajari

## Fitur Catat Uang:

- Tombol tambah, data masuk ke list
- Tampilkan semua pengeluaran dalam daftar
- Tombol hapus per item
- Total pengeluaran tampil di atas
